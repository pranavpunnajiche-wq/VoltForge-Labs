# VoltForge Labs – Electronics Repair & 3D Printing Website

A single-file static website (`index.html`): repair catalog, instant 3D print quote tool (STL upload), WebGL particle hero and dither intro animation.

## Deploy with GitHub Pages
1. Create a new repository on GitHub and upload `index.html` and this `README.md` to the main branch.
2. Open **Settings → Pages**, set the source to **Deploy from a branch**, choose `main` and `/ (root)`, then save.
3. Your site goes live at `https://<your-username>.github.io/<repo-name>/` after a minute or two.

## Before going live
- Replace the placeholder name **VoltForge Labs** everywhere in `index.html`.
- Set your real email in `const EMAIL=...` and the footer contact details.
- Update repair prices in the `ITEMS` list and print rates in `RATE` (₹ per gram).
